# A15 finite receipt contracts

Preparation only. Root's [verified specification](card-animation-a15-spec.md) supplies exact primary identities, costs, prerequisites and endings. Build these seams only after A14 data is frozen and current writers release the relevant files. Preserve all A13/A14 semantics, proofs and tests; do not install or build170 while an earlier production review is active. Engine source stays read-only.

## Shared minimum

Every rich primary uses exact canonical event/print and independently computed legal payment, actual chosen ready resource IDs, one hand→discard event, legal action phase, exact controller/owner/current entry and complete after-state agreement. Coherently altered payment or printed classification must not become valid by changing receipt and ending together. Reject unknown prerequisite/attack/phase/prevention/sequence metadata instead of ignoring it. Keep before/after snapshots immutable; actual recorded endings are never reconstructed by the staging resolver.

Actual owner destinations, surviving native stats/keywords, wound counts and all unrelated snapshot metadata remain exact. Explicit prevented outcomes require independent evidence and may not be hidden behind an otherwise plausible successful ending. Canonical source proof and supported-outcome predicate are shared by rich rendering and generic-receipt suppression. Any unsupported native departure, stat aura, trigger, attachment or leader aftermath remains generic.

- **TIE creation and generated-entry restriction:** extend existing explicit token creation with tie-fighter, exact1/1/space/token/existing JSON identity/traits vehicle+fighter, ready fresh current entry. No invented print alias, Imperial trait, played origin or temporary exhausted state. Expiry removes only the named source/current-entry restriction using explicit phase-end receipts; no readiness, draw or phase progression from the animation clock. Jerjerrod replacements need actual replacement origin and generated set; otherwise support primary8 and leave16 generic.

- **Distinct printed-title boost:** seal the complete current friendly arena entries, their verified printed titles and exact distinct-title set once, alongside source/round/phase. Each of that same current set receives exactly+N/+N with fixed phase status; no opponent or later entry receives it. `Millennium Falcon: Lando's Pride` and `Millennium Falcon: Get Out And Push` have different card identities/subtitles but the same title. Owner is separate from controller. Stat amount and recipient set never recompute on later departure/entry. No XP attachments, wound removal or permanent stats. Expiry requires exact supplied ending truth and removes only the matching status.

- **Exhausted attack permission:** a narrow event/attack/source/current-entry witness permits Dogfight's selected friendly unit to initiate this one attack while already exhausted. Its target must be an actual legal unit. It does not ready the attacker, give repeat permission, bypass Sentinel or authorize bases. The attack/exhaust receipt records whether exhaustion actually changed (ready→exhausted versus already exhausted); no invented successful ready or exhaust event. Preserve explicit supported native cross-arena allowance separately (`attackArenaPermission` already exists). Unrelated cards cannot acquire the exception by passing an arbitrary flag.

- **Pilot detach:** an actual current attachment needs explicit unit-upgrade/Pilot classification, printed identity, exact contributions, controller, owner, host/current entry and stable attachment ID. It moves from that host to ground under the same current controller, same physical card ID but fresh unit incarnation, printed unit body and exhausted pose. `DetachPilotSystem` calls unattach then arena move with ForceInitialize; `zoneMoveRequiresControllerReset` does not reset control between arenas. Remove only the Pilot's actual stat and ability contribution from host; retain other attachments, wounds, exhaustion and native abilities. A source-owned piloting ability ends when detached; a Pilot's own printed unit ability (e.g. Independent Smuggler Raid1) still applies if actually supported. This is not play/rescue/return and grants no When Played effect. Primary Determined Recruit has no conditional unit ability. Leader Pilots need actual deployed summary, side and incarnation truth; do not invent it from ordinary unit fields. Host lethal cleanup and foreign continuous effects require real additional receipts. Eject's actual draw shares a simultaneous resolution group and remains independent of whether detach exists/succeeds.

## Card-specific witnesses

- **Nebula:** supplied complete current arena set is inspected for actual attachments; every non-upgraded member gets its actual defeat or explicit prevention outcome, across both seats/zones. Tokens and deployed leaders count as units. Shield/Experience qualify as upgrades. Lurking TIE Phantom's native immunity means a receipt cannot simply remove every unupgraded body. Preserve actual protected survivors and all upgrade/owner/leader/token cleanup; primary four ordinary deaths, two upgraded survivors.

- **Apology:** first selection is a friendly current unit and second selection is any surviving current unit. Use an ordered clause/sequence identity, not a success prerequisite: actual prevention of the first defeat does not by itself prevent subsequent XP. Exactly two distinct new Experience tokens yield+2/+2 and retained owner/controller attachments, no phase status. Optional decline adds no XP. Never reuse departed target as an active recipient. Separate chooser ownership from destination.

- **Salvage:** source event0 still needs canonical resources payment with empty IDs and one source disposal. Actual selected own discard Vehicle uses its full computed legal cost via separate unit payment, fresh entry and normal exhausted entry. Bind play to source event and exact discard instance; bind the1 ability damage to that actual new entry and sequence after play/before any separately supplied queued native entry triggers. Complete payment/state conservation, no discount or free-rescue metadata. Native unit/card trigger receipts must identify real causing source and order; no trigger queue synthesis. Actual failed/prevented/replaced play cannot license arbitrary new-entry damage.

- **All Wings:** seal≤2 distinct selected current friendly space entries. Record which actual exhaustions succeeded; each create must match one distinct successful entry via source/current-incarnation witness and create exactly one own fresh exhausted X-Wing2/2. A prior exhausted or prevented target is not a success; selection alone is not enough. Explicit zero choices are valid paid source-only endings. Unit token substitutions/replacements need their own actual evidence.

- **Tandem:** two distinct attack IDs in one event sequence, actual space attacker first and ground attacker second. Second receipt requires actual first attack, not survival/damage success; the first may kill its attacker. Only second attacker receives attack-only+2/+0. Each attack has independent current target/Sentinel/Shield/arena/pose legality and actual simultaneous counterdamage or separately supported native combat order. Ending keeps no+2 and never double counts the base or the first attack. No first attack means no second; no available second can leave first-only ending. Normal legal base targets are allowed, unlike Dogfight.

- **Air Superiority:** source-bound census contains the complete current own/opponent space entries and strict count relation at resolution. Unit tokens and current controllers count. Damage target is that opponent's actual ground unit. Actual4 ability damage, separate lethal defeat and native aftermath follow existing seams. Equal/less means no effect, not an invented zero-damage targeting animation.
